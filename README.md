# Rasamsetty Hemanth — Portfolio

A responsive developer portfolio built with HTML, CSS, and vanilla JavaScript. The navy-and-teal design uses locally hosted Inter typography, a sticky introduction, section navigation, and subtle pointer lighting.

## Website

Requested Netlify address: https://rasamsettyhemanth.netlify.app

## Content

- Professional summary and full-stack training
- Tap Academy internship
- RAGbot and Academia Share projects with GitHub links
- Languages, web technologies, tools, core concepts, and soft skills
- Complete education history
- Patent record, IJSDR paper, hackathons, and club coordination
- Salesforce, IBM, and Blackbugs certifications
- Email, phone, GitHub, LinkedIn, and the Google Drive resume link

## Run locally

No dependencies or build step are required. From the repository root, run:

```sh
python3 -m http.server 8000
```

On Windows, use `py -m http.server 8000`. Open http://localhost:8000.

## Netlify

Import this repository with `main` as the production branch. Leave the build command empty and use `.` as the publish directory. The included `netlify.toml` declares the publish directory. The root `index.html` is the entry point.

## Editing

- `index.html`: portfolio text, links, and resume destination
- `styles.css`: responsive layout, typography, and colors
- `script.js`: active navigation, reading progress, pointer lighting, and email copying
- `assets/`: locally served typography and project artwork
